# nds-bridge

A tool that acts as a bridge between NDS consoles (both emulated and physical) during local wireless networked games.
It puts your WiFi device into monitor mode to talk to a physical NDS family console. 

Features:
- Uses the melonDS LAN protocol to inject itself into a LAN room and allow communication with an emulated NDS.
- Automatically attempt to maintain the connection if the OS tries to force the wireless device out of monitor mode.
- Terminal dashboard with connection information and logs.
